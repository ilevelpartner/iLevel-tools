4
HEADER

Directional retracting header

Buyer laptops render ~625 CSS px of viewport height. A static two-band header consumes ~17% permanently. Sticky wrapper with scroll-direction toggle.

▼
Scroll stateWrapper inline style
At toptop: 0px
Scrolling downtop: -{measuredHeaderHeight}px
Scrolling uptop: 0px
  • Wrapper is position:sticky with transition on top, 200ms ease-out
  • Sticky rather than fixed — no layout jump, no scroll-position correction
  • Height measured once, exposed as CSS variable. Every downstream sticky offset reads it. Do not hardcode.
  • Never retract within ~160px of top. Hold open while dropdown is expanded.
Note position:sticky fails silently inside an ancestor with overflow: hidden|auto|scroll. Check the ancestor chain first.

Acceptance

  • Logo, nav and pills all visible on one line at 1030, 1100, 1150, 1190, 1440
  • Account block collapses to avatar below ~1100px without nav wrapping
  • Header retracts on scroll-down, returns on scroll-up, no content jump
  • Nav identical on shop, PDP, cart, checkout and post-registration
